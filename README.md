# Python-Flask-html-

## Overview
This is a simple website built using:

- **HTML**: For frontend structure and layout  
- **Python**: To handle backend logic  
- **Flask**: As the web framework for routing and serving content  

The project demonstrates a basic Flask setup with templates and Python logic.
